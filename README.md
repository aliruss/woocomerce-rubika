# WooCommerce Rubika Bridge

افزونه سبک برای صف‌بندی و انتشار محصولات **منتشرشده** ووکامرس در روبیکا.

## قابلیت‌ها
- تنظیم توکن بات، کانال، URL سایت.
- قالب پیام قابل شخصی‌سازی با `{title}`، `{short_description}`، `{price}`، `{url}`.
- تشخیص قیمت محصولات ساده/متغیر و نمایش قیمت فروش ویژه با قیمت خط‌خورده.
- انتخاب تعداد تصویر ارسالی و انتخاب تصاویر مستثنی از **رسانه وردپرس** (Multi Select).
- پشتیبانی از تبدیل خودکار WEBP/AVIF و فرمت‌های ناسازگار به JPG نهایی و معتبر قبل از ارسال.
- صف انتشار با WP-Cron و فاصله زمانی قابل تنظیم (دقیقه‌ای).
- بازه زمانی مجاز انتشار روزانه + اجرای دستی صف برای تست فوری.
- دکمه انتشار یک‌کلیکی از نوار ابزار مدیریت (داخل پنل و صفحه محصول فرانت).
- از منوی «شبکه اجتماعی» در نوار ابزار ادمین، ارسال مستقیم به روبیکا بدون صف.
- دکمه inline keyboard خرید محصول در پیام. اگر محصول تصویر معتبر داشته باشد، ارسال بدون تصویر به‌عنوان ارسال موفق ثبت نمی‌شود و برای تلاش مجدد در صف می‌ماند.
- ارسال دسته‌جمعی محصولات منتشرشده به‌ترتیب دسته‌بندی/عنوان.
- دکمه پاک‌سازی صف + بخش لاگ خطا/رویداد.
- کلید روشن/خاموش برای لاگ‌گیری و کلید ریست رکوردهای synced/unsynced.
- کلید روشن/خاموش کلی افزونه + صف خودکار برای محصولات جدید منتشرشده (فقط موجود).

## نصب
1. فایل افزونه را در مسیر `wp-content/plugins/woocommerce-rubika-bridge/` قرار دهید.
2. افزونه را فعال کنید.
3. از مسیر WooCommerce → Rubika Bridge تنظیمات را تکمیل کنید.

## نکات عملکرد
- برای جلوگیری از فشار روی سرور و کانال، بازه 10 تا 20 دقیقه پیشنهاد می‌شود.
- لاگ‌ها را از همان صفحه تنظیمات بررسی کنید تا خطاهای API سریع‌تر رفع شوند.

## Changelog

### 1.2.0 - Phase 1 multi-network foundation
- نسخه افزونه در هدر وردپرس و ثابت داخلی `WCRB_Plugin::VERSION` به‌روزرسانی شد و مقدار نصب‌شده در option `wcrb_plugin_version` نگهداری می‌شود.
- ساختار صف برای چند شبکه آماده شد و ستون‌های `network`، `payload_hash`، `request_id` و `last_response` به جدول صف اضافه می‌شوند؛ داده‌های قدیمی به شبکه `rubika` مهاجرت می‌کنند.
- تنظیمات مستقل Telegram اضافه شد: فعال/غیرفعال، Relay URL، Relay API Key، HMAC Secret اختیاری، تعداد تصویر، قالب پیام، parse mode و تست اتصال relay.
- متن سفارشی سطح محصول اضافه شد: متن عمومی شبکه‌های اجتماعی، متن اختصاصی Rubika و متن اختصاصی Telegram.
- اکشن‌های ارسال محصول به Rubika، Telegram و همه شبکه‌های فعال از منوی «شبکه اجتماعی» آماده شد.
- جلوگیری از ارسال تکراری با payload hash اضافه شد؛ ارسال دستی مستقیم همچنان به‌عنوان forced resend قابل انجام است.
- کلاینت امن WordPress-to-relay برای Telegram اضافه شد. وردپرس مستقیماً Telegram Bot API را صدا نمی‌زند و توکن تلگرام در افزونه ذخیره/ارسال نمی‌شود.
- Phase 2 شامل پیاده‌سازی Python Telegram relay server خواهد بود و در این فاز فقط سمت افزونه وردپرس آماده شده است.

## Migration notes
- هنگام فعال‌سازی یا اولین اجرای افزونه، `dbDelta` ساختار جدول صف را به‌روز می‌کند.
- رکوردهای صف قدیمی که مقدار `network` ندارند با `rubika` مقداردهی می‌شوند تا رفتار قبلی حفظ شود.
- تنظیمات قدیمی Rubika حفظ شده‌اند؛ تنظیمات Telegram جدید و مستقل هستند.
