# WooCommerce Rubika Bridge

افزونه سبک برای صف‌بندی و انتشار محصولات **منتشرشده** ووکامرس در روبیکا.

## قابلیت‌ها
- تنظیم توکن بات، کانال، URL سایت.
- قالب پیام قابل شخصی‌سازی با `{title}`، `{short_description}`، `{price}`، `{url}`.
- تشخیص قیمت محصولات ساده/متغیر و نمایش قیمت فروش ویژه با قیمت خط‌خورده.
- انتخاب تعداد تصویر ارسالی و انتخاب تصاویر مستثنی از **رسانه وردپرس** (Multi Select).
- پشتیبانی از تبدیل خودکار WEBP/AVIF به JPG قبل از ارسال (در صورت نیاز).
- صف انتشار با WP-Cron و فاصله زمانی قابل تنظیم (دقیقه‌ای).
- بازه زمانی مجاز انتشار روزانه + اجرای دستی صف برای تست فوری.
- دکمه انتشار یک‌کلیکی از نوار ابزار مدیریت (داخل پنل و صفحه محصول فرانت).
- از منوی «شبکه اجتماعی» در نوار ابزار ادمین، ارسال مستقیم به روبیکا بدون صف.
- دکمه inline keyboard خرید محصول در پیام.
- ارسال دسته‌جمعی محصولات منتشرشده به‌ترتیب دسته‌بندی/عنوان.
- دکمه پاک‌سازی صف + بخش لاگ خطا/رویداد.
- کلید روشن/خاموش برای لاگ‌گیری و کلید ریست رکوردهای synced/unsynced.
- کلید روشن/خاموش کلی افزونه + صف خودکار برای محصولات جدید منتشرشده (فقط موجود).

## نصب
1. فایل افزونه را در مسیر `wp-content/plugins/woocommerce-rubika-bridge/` قرار دهید.
2. افزونه را فعال کنید.
3. از مسیر WooCommerce → Rubika Bridge تنظیمات را تکمیل کنید.

## نکات عملکرد
- برای جلوگیری از فشار روی سرور و کانال، بازه 10 تا 20 دقیقه پیشنهاد می‌شود.
- لاگ‌ها را از همان صفحه تنظیمات بررسی کنید تا خطاهای API سریع‌تر رفع شوند.
